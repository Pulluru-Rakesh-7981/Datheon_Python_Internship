# Hangman Word Guessing Game

A simple console-based Hangman game developed using Python. The player guesses the hidden word one letter at a time with a maximum of 6 incorrect attempts.

# Features

- Random word selection
- Letter guessing
- Tracks correct and incorrect guesses
- Displays Hangman stages
- Win and lose conditions

# Technologies

- Python 3
- Random module
